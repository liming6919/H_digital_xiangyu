# 手指控制使用说明

## 快速开始

手指控制已集成到数字人系统中，默认启用。启动数字人系统时会自动初始化手指控制器。

### 1. 安装依赖

```bash
pip install pyserial
```

或使用requirements.txt：

```bash
pip install -r requirements.txt
```

### 2. 设置串口权限

```bash
sudo chmod 666 /dev/ttyUSB1  # 根据实际设备修改
# 或
sudo usermod -a -G dialout $USER
```

### 3. 启动数字人系统

```bash
cd digital_human_system
python3 main.py --enable-finger --finger-port /dev/ttyUSB1
```

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--enable-finger` | 启用手指控制 | 默认启用 |
| `--disable-finger` | 禁用手指控制 | - |
| `--finger-port` | 手指舵机串口设备路径 | `/dev/ttyUSB1` |
| `--finger-baudrate` | 手指舵机串口波特率 | `115200` |

## 手势映射示例

当数字人执行以下手势时，手指会自动调整：

- **点赞** (`thumbs_up`): 拇指竖起，其他手指弯曲
- **握手** (`handshake`): 手指自然弯曲
- **指向** (`point`): 食指伸直，其他手指弯曲
- **握拳** (`fist`): 所有手指弯曲
- **张开** (`open_hand`): 所有手指伸直
- **休息** (`rest`/`neutral`): 手指轻微弯曲

## 测试

### 测试串口连接

```python
from finger_control import ServoController

# 测试单个舵机
with ServoController('/dev/ttyUSB1', 115200) as servo:
    servo.set_debug(True)
    servo.set_servo_position(1, 500, 500)  # 舵机1移动到中间位置
```

### 测试手指控制

```python
from finger_control import FingerController

# 测试手指控制
with FingerController('/dev/ttyUSB1', 115200, debug=True) as finger:
    finger.update_gesture('thumbs_up', duration=1.0)
    time.sleep(2)
    finger.update_gesture('rest', duration=1.0)
```

## 故障排除

### 串口打开失败

1. 检查设备是否存在：`ls -l /dev/ttyUSB*`
2. 检查权限：`sudo chmod 666 /dev/ttyUSB1`
3. 检查是否有其他程序占用：`lsof /dev/ttyUSB1`

### 手指无响应

1. 检查串口连接和波特率
2. 检查舵机ID配置（默认1-10）
3. 启用debug模式查看发送的指令：`--finger-port /dev/ttyUSB1 --enable-finger`

### 手指动作不匹配

在 `finger_control/finger_mapper.py` 中添加或修改手势映射。

## 自定义配置

### 修改手指配置

```python
from finger_control import FingerController

controller = FingerController()
controller.finger_mapper.update_finger_config({
    'left_thumb': 1,    # 左手拇指 -> 舵机1
    'left_index': 2,    # 左手食指 -> 舵机2
    # ... 其他手指
})
```

### 添加新手势映射

```python
from finger_control import FingerMapper

mapper = FingerMapper()
mapper.add_gesture_mapping('custom_gesture', {
    'left_thumb': 90,
    'left_index': 180,
    'left_middle': 0,
    'left_ring': 0,
    'left_pinky': 0,
    'right_thumb': 90,
    'right_index': 180,
    'right_middle': 0,
    'right_ring': 0,
    'right_pinky': 0,
})
```

## 与数字人系统集成

手指控制已完全集成到数字人系统中：

1. **自动初始化**：启动数字人系统时自动创建手指控制器
2. **同步执行**：手势执行时自动更新手指动作
3. **语义映射**：根据手势名称自动映射到相应的手指姿态

无需额外代码，启动数字人系统即可使用！
